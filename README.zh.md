# dsh-chat-search 对话搜索插件

[English](README.md) | 简体中文

专为 DeepSeek Harness (DSH) 打造的会话检索与上下文锁定插件，支持全局跨任务会话搜索与当前会话内精准检索。

## ✨ 特性

- 🌐 **全局任务搜索 (跨所有会话)**：
  - 极速扫描本地所有历史会话（支持多工作区），内存缓存加速使得重复检索响应仅需十几毫秒；
  - 智能提取匹配关键词的前后上下文文本（带关键字高亮）；
  - 支持按任务会话折叠/展开，清晰展示角色（用户/助手）、轮次与更新时间；
  - 点击任意匹配项或会话，自动跨会话跳转，并通过发光脉冲动效精准定位目标消息行。

- 💬 **当前会话内搜索**：
  - 在当前打开的任务中实时过滤每一轮提问与回复；
  - 支持「上一处 / 下一处」顺序跳转，支持键盘快速导航。

- 🎯 **上下文精准锁定**：
  - 三重 DOM 锚点定位策略（`data-chat-anchor-key` / `data-chat-node-key` / `data-chat-turn`）；
  - 平滑滚动入视野 + 2.5 秒金色/脉冲蓝光圈呼吸高亮（`dsh_cs_flash`），让您一眼锁定对应内容。

- ⌨️ **便捷快捷键**：
  - `Ctrl + Shift + F` / `Alt + F`：全局快速呼出搜索面板；
  - `Ctrl + F`：呼出当前会话内搜索；
  - `Enter` / `Shift + Enter`：当前对话内快速跳到下一处 / 上一处；
  - `Esc`：快速关闭搜索面板。

- 🎨 **完美适配原生主题**：
  - 采用 DSW 主题 CSS 变量，完美兼容深色与浅色模式；
  - 右下角提供精致的玻璃拟态悬浮按钮（🔍），随时一键展开。

## 📦 安装

在 DSH 终端或命令行中执行：

```sh
dsh plugin --profile web add helo060228/dsh-chat-search
```

或者通过 DSH 插件市场搜索 `dsh-chat-search` 一键安装。
